# Theodicy Builder

A student companion to the *Problem of Evil: Augustine and Irenaeus/Hick* workbook (A-level Religious Studies).

- **Plan the narrative** – write the Augustine and Irenaeus/Hick narratives beat by beat, with hints, a word-count target and a must-include key-terms tracker.
- **Sort the statements** – place the workbook statements under each heading, check answers, get hints, and unlock the suggested order.

Single self-contained page: open `index.html` or publish with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
Students' work is saved only in their own browser (localStorage).
